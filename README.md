# PMO Tracker — ระบบติดตามงานทีมการตลาดดิจิทัล

ระบบนี้ใช้แทนไฟล์ Excel ที่ส่งต่อกันทาง LINE โดยเก็บข้อมูลไว้ที่ฐานข้อมูลกลางที่เดียว ทุกคนจึงเห็นข้อมูลล่าสุดชุดเดียวกัน ระบบบันทึกทุกการแก้ไขไว้ใน Activity Log และย้อนกลับการแก้ไขได้

> ไฟล์ฟอนต์ Mornamchi ไม่ได้อยู่ใน repository นี้ (สงวนสิทธิ์ใช้ภายใน มมส) ให้คัดลอก `Mornamchi-Light.woff2`, `Mornamchi-Regular.woff2`, `Mornamchi-Bold.woff2` จากชุดฟอนต์ของมหาวิทยาลัยไปไว้ที่ `static/fonts/` ถ้าไม่มีไฟล์ หัวเรื่องจะใช้ฟอนต์ Prompt แทน

**Stack:** SvelteKit 3 (SSR) · Tailwind 4 · shadcn-svelte · Drizzle ORM · SQLite (libSQL) → Cloudflare D1 / Pages

## เริ่มใช้งาน

```bash
npm install
npm run db:reset   # สร้างตาราง + นำเข้าข้อมูลจาก data/project_tracking_sample.xlsx
npm run dev
```

ระบบใหม่มี 3 สถานะ ส่วนสถานะ "รอตรวจ" ใน Excel จะรวมไว้ใน **Doing** และติดป้าย `[รอตรวจ]` ในหมายเหตุ คอลัมน์ "วันคงเหลือ" และ "สถานะเวลา" ไม่ได้เก็บลงฐานข้อมูล ระบบคำนวณจากวันนี้ทุกครั้งตามเกณฑ์เดิม (เกินกำหนด = ยังไม่เสร็จและเลยวันกำหนดส่ง, ใกล้ครบกำหนด = เหลือไม่เกิน 3 วัน)

## กันข้อมูลถูกเขียนทับ

- งานทุกชิ้นมี `version` หากมีคนแก้งานหลังจากที่คุณเปิดหน้านั้น การบันทึกของคุณจะถูกปฏิเสธ แล้วระบบจะให้โหลดข้อมูลล่าสุดก่อน
- `activity_logs` เก็บค่าก่อนและหลังของทุกฟิลด์ที่เปลี่ยน กด "ย้อนกลับ" ได้ที่หน้างานหรือหน้า Activity Log (การย้อนกลับจะถูกบันทึกเป็นรายการใหม่ ประวัติเดิมไม่หาย)
- พนักงานที่ลาออกให้ใช้ "ปิดการใช้งาน" แทนการลบ เพื่อเก็บประวัติไว้

## Deploy ขึ้น Cloudflare Pages + D1

ระบบอ่านฐานข้อมูลตามสภาพแวดล้อม: ตอน `npm run dev` ใช้ `local.db` และบน Cloudflare ใช้ D1 binding `DB` ([db/index.ts](src/lib/server/db/index.ts))

ทดสอบแบบ Cloudflare ในเครื่อง:

```bash
npm run build
npm run d1:migrate:local      # สร้างตารางใน D1 จำลอง
npm run d1:seed:local         # คัดลอกข้อมูลจาก local.db ขึ้น D1 จำลอง
npm run preview               # http://localhost:4173
```

Deploy จริง:

1. `npx wrangler d1 create pmo-db` แล้วนำ `database_id` ที่ได้มาใส่ใน `wrangler.jsonc`
2. `npx wrangler d1 migrations apply pmo-db --remote`
3. ข้อมูลเริ่มต้น: `npm run db:export-sql` แล้วรัน `npx wrangler d1 execute pmo-db --remote --file=drizzle/seed.sql`
4. `npm run build` แล้ว `npx wrangler pages deploy`

เมื่อแก้ `schema.ts` ให้รัน `npm run db:generate` เพื่อสร้างไฟล์ migration ใหม่ในโฟลเดอร์ `drizzle/`

ระบบ hash รหัสผ่านใช้ Web Crypto (PBKDF2) จึงทำงานบน Workers ได้ทันที
